# Zoom Chat Copy

A static, single-page tool for building Zoom chat copy for A Heart For Healing sessions with Rev. AdaRa Walton, N.D., Ph.D.

Open `index.html` in a browser (or host this repo with GitHub Pages). Fill in the song and scripture details, switch between the fun emoji version and the plain version, and use the Copy button on each block: Welcome, Tonight's music, and Scripture.

The page is fully responsive for phone, tablet, and desktop, and its theme defaults to System, so it follows your computer or phone's light/dark setting. You can also force Light or Dark, and that choice is remembered in your browser.

Scripture lookup: each verse has a link to the matching George Lamsa Translation chapter on StudyLight, so you can check the exact wording and paste it in. Verses you save are stored in your browser only (localStorage), not on a server, and Start fresh clears tonight's song and verses while keeping your saved library.

This is the static version of the Zoom Chat Copy app built in Muse. The Muse version also keeps a server-side verse library; this static version keeps its library in the browser you open it in.
